Проект представляет собой backend-часть веб-приложения для размещения объявлений. 
Пользователи могут регистрироваться, публиковать объявления с фотографиями, оставлять 
комментарии, изменять свои данные и аватар. Реализована ролевая модель (USER и ADMIN), 
разграничение прав доступа к операциям. Все данные хранятся в базе данных PostgreSQL. 
API документировано с помощью Swagger/OpenAPI.

Используемые технологии
Java 11 – язык разработки
Spring Boot 2.7 – основной фреймворк
Spring Security – аутентификация и авторизация (Basic Auth)
Spring Data JPA – работа с базой данных
PostgreSQL – СУБД
Lombok – генерация кода
Swagger (springdoc-openapi) – документация API
BCrypt – шифрование паролей
Maven – сборка проекта
CORS – поддержка кросс-доменных запросов (настроено для localhost:3000)

Функциональные возможности
Регистрация и вход пользователей (Basic Auth)
Просмотр всех объявлений без авторизации
Создание, редактирование, удаление объявлений (только для авторизованных, с проверкой прав)
Загрузка и обновление изображений для объявлений и аватаров
Добавление, редактирование, удаление комментариев к объявлениям
Управление своим профилем (смена пароля, обновление данных, аватара)
Администратор имеет права на удаление и редактирование любых объявлений и комментариев
